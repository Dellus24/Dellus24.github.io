# ── THE LANDING ────────────────────────────────────────────────────────────
# Which windows greet a visitor, and where they sit. Compose it by hand, or —
# far easier — open the site with ?layout on the end of the URL, drag and
# resize until it looks right, press Copy, and paste over the block below.
#
# EVERY WINDOW KIND THE SITE HAS CAN GO HERE:
#
#   <project>  image <file>   one picture from that project's gallery/
#                             a thumbs/ prefix loads the 400px derivative
#   <project>  model [file]   the 3D viewer; name a .glb only if that project
#                             has more than one
#   <project>  gallery        that project's whole thumbnail grid
#   <project>  slides         that project's slideshow
#   <project>  box            that project's text box, as it opens normally
#   about | cv | contact      the static panels
#   text                      this file's own text, below the ---
#   menu                      the site menu itself
#
# A `model` line also carries HOW THE MODEL LOOKS — shape it in the viewer
# (orbit, zoom, mode, Deconstruct) and Copy writes it out:
#
#   101-gates model Detail.glb  at 20 3 size 45 90  angle 120 -25 zoom 4.1 spin 0 decon 65
#
# spin 0 is what makes it hold still; without it the model rotates away from
# whatever angle you set. See assets/projects/README.md for every key.
#
# Optionally followed by  at <x> <y>  size <w> <h>  — all PERCENTAGES of the
# screen, so a composition holds on any display. Geometry is ALL-OR-NOTHING:
# unless every line carries both, the numbers are ignored and the landing
# auto-tiles instead. A window will not go narrower than 260px whatever you
# ask for — .win-frame has that as a floor.
#
# WEIGHT IS THE CONSTRAINT. The initial load is ~404 KB. Measured 2026-09-29:
#
#     Floor Detail.glb     14 KB      gallery thumb       5-20 KB
#     silo.glb            105 KB      gallery full-size  500-800 KB
#     spring.glb          651 KB      a slideshow preloads ~1.7 MB
#     Detail.glb          1.1 MB
#     Cabine.glb          1.4 MB
#     Pavilion Model.glb  3.0 MB
#
# The three below were picked on weight alone (~140 KB) while the system was
# being built. They are placeholders — what the landing should actually show
# is yours.
